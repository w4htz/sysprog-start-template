## 1.1 С для системного программиста

Написать функцию на С, которая получает сведения о системе и возвращает их в структуре фиксированного размера.

Реализовал ядро, которое возвращает PID, число логических процессоров, размер страницы памяти и имя компьютера. Проверил размер структуры, смещения полей и обработку пустого указателя.

Сборка и запуск из папки `agent/core` на Windows (в среде x64 Native Tools Command Prompt for VS 2022):

```cmd
cl /nologo /W4 /WX show_info.c core_info.c
show_info.exe
```
