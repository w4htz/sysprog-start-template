## 1.3 n8n и Ollama

Передать событие `agent_started` в вебхук, получить пояснение от локальной модели и подготовить тестовое письмо.

[Скриншот проверки n8n](<Снимок экрана 2026-11-18 164946.png>) · [Скриншот проверки Mailpit](<Снимок экрана 2026-11-18 164950.png>)

Подготовил отправку события `agent_started` из `brain.py` и сценарий `agent-started.json` для импорта в n8n. В сценарии вебхук передаёт данные в цепочку с Ollama, а её ответ используется в тестовом письме.

Для запуска в n8n импортируйте `agent-started.json`, подключите локальную Ollama (`http://127.0.0.1:11434`) и тестовый SMTP (Mailpit на порту `1025`). Запустите прослушивание тестового вебхука и выполните из папки `agent/`:

```cmd
py brain/brain.py http://localhost:5678/webhook-test/agent --library core/sentry_core.dll
```

Проверил всю цепочку локально на Windows. n8n принял POST и вернул HTTP 200. Модель `qwen2.5:3b` сформировала объяснение, а Mailpit получил письмо с пояснением и исходным JSON. В пояснении модель ошиблась в единицах — `page_size: 4096` означает 4096 байта, или 4 КиБ, а не килобайт.

```text
1.3 · n8n, Ollama и Mailpit

agent_started: HTTP 200
В Mailpit найдено письмо: Агент запущен: DESKTOP-1JEF7SJ
Ответ Ollama: Системный агент Windows 32-разрядная (win32) запрашивает доступ. Он использует CPU 16-разрядных процессоров (16) и размер страницы памяти 4096 килобайт на хосте DESKTOP-1JEF7SJ.

Исходные данные:
{
  "event": "agent_started",
  "os": "win32",
  "pid": 14820,
  "cpus": 16,
  "page_size": 4096,
  "host": "DESKTOP-1JEF7SJ"
}
```
